# WarmUp 🎙️

**WarmUp** is an open-source, local-first mock interview simulator designed to help job-seekers practice technical and behavioral interviews with zero stress and zero subscription fees.

Built with **Gemma 2 (2B)** via Ollama and native Web Speech APIs.

---

## 🚀 Key Features

- **100% Private & Local:** All inference runs on your machine via Ollama. No transcripts or voice data are stored or uploaded to cloud servers.
- **Multiple Personas:**
  - **Sarah (HR Recruiter):** Focuses on behavioral assessments and the STAR framework.
  - **Alex (Tech Lead):** Probes architecture trade-offs, scalability, and code structure.
- **Voice-to-Voice Interaction:** Talk directly via your browser's microphone and hear spoken follow-up questions.
- **Instant Scorecard:** Generates a constructive feedback report highlighting clarity, conciseness, and next steps.
